Step by step

Each test case runs through the same stages as the Recommendation. For every stage the ITU reference logs its result, so we compare stage by stage and see where any difference starts. Deviation is GroundLink minus reference, in dB.

Where the final loss differs

No ducting

GroundLink leaves out ducting and layer reflection (P.1812 §4.4). It only matters for small time percentages, where the atmosphere can bend signals far beyond normal range. Leaving it out predicts more loss, which is the safe side for planning.

All test cases

How it was run

The ITU-R Working Party 3M validation set has 19 terrain profiles and 63 test cases: land, sea and mixed paths of 1 to 235 km, 30 MHz to 6 GHz, 1 to 50% of time, horizontal and vertical polarisation, with and without clutter. Every case runs through GroundLink's own engine (src/coverage/p1812.js, the code the coverage map uses) with the reference's inputs: frequency, time percentage, antenna heights, polarisation, refractivity (ΔN, N₀), path-centre latitude, sea fraction and land stretches, terrain and clutter heights. Location variability is off (pL = 50%, σL = 0), as in the reference.

The profiles themselves are not published here, and neither are coordinates or terrain heights. This page holds only the deviations. To reproduce, download the validation set and run:

node scripts/validate-p1812.mjs /path/to/Py1812/tests

The engine is a P.1812-6 core whose path geometry (horizon angles, angular distance, multipath distances, smooth-earth correction) and clutter at the antennas follow P.1812-8. That alignment came out of this validation. Before it, diffraction on cluttered paths differed by up to 8 dB, troposcatter by up to 111 dB, and the older separate clutter loss at the antennas added up to 57 dB in urban cases.

P.1812-8 counts clutter next to an antenna through the terrain profile. The coverage map therefore samples each path densely near both antennas (25 to 400 m), so the trees and buildings around a handheld radio still block it.

What this does and does not show

It shows that GroundLink computes P.1812 the way the ITU reference does, to a thousandth of a dB, and exactly where and why it deliberately departs from it. It does not show how well P.1812 predicts real signals in your terrain. That needs field measurements, which is the next step for this page.
