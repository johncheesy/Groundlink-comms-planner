# M37 — Mission Brief Export

> **Status: spec — Jun 2026.** Eén klik: printbaar HTML-rapport met kaartafbeelding, PACE-plan, link budgets en radio-config.

---

## Waarom

GroundLink exporteert nu data-formaten (KMZ, GeoJSON, GeoTIFF, CivTAK) — maar niets dat een mens in het veld direct kan lezen. Na een planning sessie wil een operator een brief kunnen printen of als PDF opslaan: kaart van het gebied, PACE-plan, welke radio's op welke frequentie, link budgets voor elke site.

Maven's eindproduct is altijd een "strike package" — een complete, overdraagbare documentatie van de beslissing. M37 is GroundLink's equivalent: het **mission brief** als overdraagbaar document.

---

## Scope

**In scope:**
- Eén HTML-pagina (print-ready, A4 portrait)
- Ingebedde kaartafbeelding (screenshot van huidige map view)
- PACE-plan tabel
- Link budget tabel per site-paar (uit M14 data als beschikbaar)
- Radio-config tabel (uit M5/M7 data)
- Coverage-samenvatting (% covered, dead zones, model)
- Frequentie-plan (kanalen per tier)
- Missie-metadata (naam, datum, AOI, coördinaten — OPSEC: optioneel maskeerbaar)
- Exportknop in toolbar + ⌘K: "Export mission brief"

**Buiten scope:**
- PDF-generatie in-browser (te zwaar/afhankelijkheden) — user print-to-PDF via browser
- Word/DOCX
- Logo/classificatiemarkering per organisatie (later, als template-systeem)
- Online delen / upload

## B. Kaartafbeelding

### Methode: MapLibre canvas export
MapLibre GL JS exposeert `map.getCanvas().toDataURL('image/png')`. Dit werkt alleen als de map `preserveDrawingBuffer: true` heeft bij initialisatie.

**Actie nodig:** controleren of dit al ingesteld is in `src/map/map.js`. Zo niet, toevoegen. Kleine prestatie-impact (GPU buffer niet geflushed na elke frame), maar acceptabel.

```js
// src/map/map.js (controleren / toevoegen)
const map = new maplibregl.Map({
  …
  preserveDrawingBuffer: true,  // vereist voor canvas export
});
```

Exporteer: `map.getCanvas().toDataURL('image/png')` — data URL direct als `<img src>` in het HTML-brief.

## C. `src/export/brief.js` (nieuw)

```js
/**
 * M37 — Mission Brief generator.
 * Assembleert een print-ready HTML string van de huidige app-state.
 */
export function generateBrief({
  missionName,
  mapImageDataUrl,
  coverageSummary,   // van summarizeCoverage()
  paceResult,        // van buildPace()
  radios,            // van M5 mix output
  linkBudgets,       // van M14 data (optioneel)
  modelInfo,         // { label, margin, percentile }
  buildVersion,
}) → string  // complete HTML document string

/** Open de brief in een nieuw tabblad (klaar voor Ctrl+P / print-to-PDF). */
export function openBrief(htmlString) {
  const blob = new Blob([htmlString], { type: 'text/html' });
  const url = URL.createObjectURL(blob);
  window.open(url, '_blank');
  // Revoke na 60 s (genoeg tijd om te printen)
  setTimeout(() => URL.revokeObjectURL(url), 60_000);
}
```

## E. OPSEC

Het brief bevat coördinaten van de AOI en sites. Standaard worden deze getoond (de gebruiker heeft ze zelf ingevoerd). Optioneel:
- Checkbox "Masker coördinaten" → vervangt lat/lng door "zie missiebestand"
- Standaard: coördinaten zichtbaar (anders is het brief niet bruikbaar)

De OPSEC footer-tekst wordt altijd getoond — herinnert de gebruiker aan de gevoeligheid.
